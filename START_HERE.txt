NIGHT MEMO — WORD-LIKE MANAGER EDITOR PROTOTYPE
==============================================

This is a NEW, independent GitHub repository. Do not upload it over
night-memo-demo-staging and do not run any Supabase SQL.

1. Create https://github.com/new with repository name:
      night-memo-editor-prototype
2. Extract the ZIP and upload ALL contents to the repository ROOT.
   Preserve the hidden .github/workflows/deploy.yml folder/path.
   Do not upload the ZIP itself into GitHub.
3. Commit to the main branch.
4. Settings > Pages > Source: GitHub Actions.
5. Actions > Verify and deploy prototype: confirm green tick.
6. Open https://tkchan002.github.io/night-memo-editor-prototype/

Inside the prototype, click the white document to type.
In the right sidebar, change Ward F10 PM admissions (3 -> 6) and click
Update generated figures. Its total should change from 5 -> 8 without
removing the user's free text. Try Save draft, Reopen and Print.

All data are synthetic. Never enter real patient information.

Verification during creation: 10/10 Node/data-model tests passed.
Full Canvas Editor npm installation, Vite build and actual browser printing
were not possible to run in this creation environment; GitHub Actions is
configured to perform the installation, tests and build on your repository.
Please share any failing GitHub Actions log rather than applying code patches.
